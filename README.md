# RefCheck: 논문 검토 도우미 (MVP)

## 쓰는 법

1. `RefCheck.html`을 **Chrome 또는 Edge**에서 엽니다 (더블클릭). 설치할 것은 없고, 학술 API를 부르기 때문에 인터넷 연결은 필요합니다.
2. **PDF 업로드**를 누르거나 PDF를 창에 끌어다 놓습니다.
3. 10~30초 뒤 탭 3개에 결과가 나옵니다: ① 중복성 ② Reference O/X ③ 유사 주제 연구.
4. 결과는 브라우저에 자동 저장됩니다. **검토 이력 ▾**에서 다시 열 수 있고, **내보내기 (Excel)** 로 시트 3개짜리 xlsx를 받습니다.

- **이력 백업 / 복원:** 검토 이력은 브라우저 안에 저장됩니다. 브라우저의 "인터넷 사용 기록 삭제"에서 사이트 데이터까지 지우면 이력도 함께 지워집니다. 가끔 **이력 백업**으로 JSON 파일을 받아 두세요.
- **⚙ 설정:** 중복성 "주의" 기준값(기본 40%), 유사 논문 수(기본 20), API 연락용 이메일(선택).
- **추출 정보:** 결과 위의 "추출 정보"를 펼치면 뽑아낸 제목·초록·키워드와 참고문헌 원문 블록이 보입니다. 참고문헌 개수가 맞는지 여기서 확인할 수 있습니다.

## 판정 기준

| 화면 | 기준 |
|---|---|
| Reference **O** | CrossRef 또는 OpenAlex에서 찾았고, 제목 유사도 85 이상, 제1저자·연도 일치 |
| Reference **X** | 못 찾음 / 제목만 비슷함 / 연도 불일치 / 제1저자 불일치 / DOI 오류. 이유는 사유 칸에 적힘 |
| "(경미)" | 연도가 1년 차이이고 프리프린트(arXiv 등)가 끼어 있는 경우. X로 두지만 대개 문제없음 |
| "(참고)" | 저널·학회명 표기가 DB와 다름. 약어 차이가 흔해서 O/X에는 반영하지 않음 |
| **–** (확인 못 함) | 네트워크 오류, 또는 한글 문헌이라 국내 DB(KCI)가 필요한 경우 |
| 중복성 | TF-IDF 코사인 유사도. 전체 점수 = 가장 비슷한 1편의 점수. 외부 논문은 초록 단위, 이전 투고분은 본문 앞부분까지 비교 |

## 파일 구성

```
RefCheck.html        실행 파일
css/style.css        학술지 지면 스타일 (밝은/어두운 테마)
img/logo.svg         로고·브라우저 탭 아이콘 (버튼 아이콘은 RefCheck.html 안의 SVG 모음)
js/text.js           문자열 정규화, 제목 비교, TF-IDF, 겹치는 구절
js/pdf-extract.js    PDF → 제목·초록·키워드·본문·참고문헌 블록 (2단 편집 처리)
js/refs-parse.js     참고문헌 항목 분리, DOI·연도·제1저자·제목 추정
js/api.js            CrossRef / OpenAlex 호출, 동시 요청 제한, 캐시
js/ref-verify.js     기능 2: O/X 판정
js/similar.js        기능 3: 유사 주제 검색
js/duplicate.js      기능 1: 중복성
js/store.js          IndexedDB 저장, 백업/복원
js/export.js         Excel 내보내기
js/app.js            화면
lib/                 pdf.js 3.11.174, SheetJS 0.18.5 (cdnjs에서 받은 사본)
tests/test.html      자동 점검 (브라우저로 열면 실행)
```

`tests/test.html`(15개 항목)은 Chrome에서 파일을 직접 연 상태(file://)로도 15/15 통과했습니다. pdf.js 읽기, 브라우저 저장소, 실제 API 호출이 서버 없이 동작한다는 뜻입니다.

**샘플에서 나온 X 판정 (원문과 대조해 본 결과)**
- 「실내 저조도…」 1번: Alcantarilla 외 "Fast explicit diffusion…" 은 2011로 적혀 있으나 실제로는 BMVC **2013** 발표 → 실제 오기
- 「실내 저조도…」 13번: KCC2019 국내 학술대회 논문으로, CrossRef·OpenAlex에 없음 → 직접 확인 필요
- 「학습 가능한…」 6번: 제1저자를 "H. Zang"으로 적었으나 실제는 **Heng Zhang** → 실제 오기
- 「학습 가능한…」 7번: arXiv 2021 프리프린트, 출판본은 2022 → "(경미)"
- 「시그멘테이션…」 2번: GitHub 데이터셋 주소 → "확인 못 함(–) · 웹 자료" (학술 DB 대상이 아님)
- 「시그멘테이션…」 1번은 PDF가 영어 단어를 줄 끝에서 하이픈 없이 잘라 놓아("usi / ng") 처음에 제목 불일치로 나왔습니다. 잘린 단어도 맞춰 보도록 고친 뒤 O로 나옵니다

**중복성에서 발견한 것:** 「실내 저조도…」 PDF는 OpenAlex에 이미 출판된 같은 논문(대한공간정보학회지 2024, 국문 초록)과 **82%** 로 "주의"가 떴습니다. 국문 요약까지 비교하기 때문에 잡힌 결과입니다.

## 알려진 한계

- **영어 논문 우선.** 영문 초록이 있는 국내 논문은 읽을 수 있게 했습니다("요약/要旨", "참고문헌", "핵심용어" 등 인식). 다만 한글로 쓴 참고문헌은 KCI 연동(v2) 전까지 "확인 못 함"으로 나옵니다.
- **Semantic Scholar 미사용.** API 키 없이 요청하면 첫 요청부터 한도 초과(429)로 거절되어 뺐습니다. 조회 순서는 CrossRef → OpenAlex입니다.
- **CrossRef 속도.** 이메일 없이 쓰면 동시 요청이 1개로 제한되어 참고문헌 1건에 약 1초 걸립니다. 설정에 이메일을 넣으면 3개까지 늘어납니다.
- **이전 투고분끼리의 유사도.** 같은 분야(영상 강화)의 한글 논문끼리는 공통 단어 때문에 20% 안팎이 나옵니다. 기준값 40%보다 낮아 "주의"는 뜨지 않습니다.
